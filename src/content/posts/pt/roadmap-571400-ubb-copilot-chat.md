Pesquisando uma informação para um cliente, encontrei o Roadmap Item 571400, que achei interessante compartilhar:

**Microsoft Copilot (Microsoft 365): Chat: Access to UBB models via the model selector**

> Users will be able to access models that require usage-based billing (UBB) from the model selector in Chat. Tenant admins will need to allocate credits so that users can interact with these models. If users consume their allotted credits, they will be able to request credits from their tenant admins.

**Preview prevista:** novembro de 2026  
**Início do rollout previsto:** dezembro de 2026

Basicamente, a novidade é o acesso a modelos com cobrança por consumo diretamente pelo seletor de modelos do Copilot Chat.

Isso é interessante para quem utiliza bastante os modelos mais avançados e se depara com mensagens de limite de uso alcançado. A documentação de licenciamento da Microsoft descreve uma opção, ainda indicada como *coming soon*, para continuar utilizando esses recursos via UBB (*Usage-based billing*) depois de atingir os limites incluídos na licença por usuário (USL).

Combinando essas duas informações, o usuário poderá optar pelo uso de modelos disponíveis via UBB no seletor do Chat, consumindo Copilot Credits. Para isso, o administrador precisará configurar a política de cobrança e disponibilizar os créditos. Se o saldo alocado acabar, o roadmap prevê a possibilidade de solicitar mais créditos ao administrador.

UBB é a modalidade de cobrança por consumo também utilizada em experiências como Copilot Cowork, Code e Autopilot. Ela complementa a licença por usuário, não a substitui.

Outro ponto interessante é que a documentação de UBB cita modelos como Astra e Fable. O item 571400 ainda não especifica quais modelos estarão disponíveis no seletor do Chat, então vale acompanhar essa lista quando o recurso for disponibilizado.

As datas do roadmap são estimativas e podem mudar.
